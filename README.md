# UFO Web

Drop files or a folder. Investigate them with your agent. Nothing leaves your browser.

UFO Web is the open-source browser edition of [Universal File Opener](https://universalfileopener.com).
It exposes a file-investigation workspace to AI agents through [WebMCP](https://github.com/webmachinelearning/webmcp):
the agent does the cross-file reasoning, the human makes the calls.

Work in progress for the WebMCP Challenge. Full README to follow.
